# Why these investigations

Four GPT-6 Luna agents configured with high reasoning effort independently
examined primary evidence, data feasibility, practical opportunity, and the AGED
extension. This is an AI-assisted research program; the repository's outputs are
auditable computations, not independent experimental observations by a laboratory.

## Initial disagreement and resolution

- The evidence reviewer ranked keratinocyte spatial analysis first because it
  directly measures a voltage-sensitive signal in a senescence model. The review
  later withdrew an initially suggested predictive R² gate: cross-assay replicate
  pairing and donor diversity were not established.
- The data reviewer initially proposed comparing barium-adapted planarian heads
  with regeneration-associated aging reversal. Species/tissue mismatch, low n,
  and absence of a convenient deposited count matrix weakened that route. The
  nine bulk-tail FASTQ libraries alone were advertised at 32.6 GB compressed.
- The practical-strategy reviewer favored a regenerative-memory model benchmark,
  then found direct overlap with existing tools and a 2026 public reduced-model
  implementation. A future benchmark might be valuable, but a fresh simulator
  would not be the strongest initial longevity contribution.
- The AGED reviewer identified a compact extension that tests whether the
  evolutionary signal survives measurable-gene backgrounds and gene-property
  controls. The existing repository reproduces a limited enrichment analysis,
  which must not be described as reproducing the entire AGED paper.

The selected program combines a direct measurement audit with human expression
tests. Cross-study agreement is triangulation across different biological
contexts, not a shared causal experiment. Every workstream must preserve that
distinction in its conclusions.

## Resource decisions

Use local processed matrices, bounded selective image retrieval, and source-linked
manifests. Image acquisition is conditional on verifiable archive contents and
sample labels. An access or label failure remains an explicit unresolved branch;
it must not be replaced by synthetic “biological” observations.

## Advancement rule

Advance a biological prediction only when the result is measurable, survives its
specified controls, and has an interpretable alternative explanation that the
next experiment can discriminate. A weak result can still justify a better
measurement design. An unresolved access condition justifies a data request,
not a positive biological conclusion. No outreach is sent by this project run.
